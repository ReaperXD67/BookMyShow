# BookMyShow — Low-Level Design Track

![Status](https://img.shields.io/badge/status-no_implementation_published-6b7280)

This public repository currently contains no implementation to evaluate or run.

The intended learning scope is a cinema-booking domain: shows and seat inventory, temporary seat holds, booking state, payment outcomes, and concurrency around the last available seat. Those are design goals, not completed features.

## Before this becomes portfolio-ready

- Publish the domain model and state transitions.
- Implement atomic seat hold/confirm/release behavior.
- Add idempotent booking and payment boundaries.
- Cover concurrent booking attempts with deterministic tests.
- Document the API and persistence trade-offs with an architecture diagram.

Until those artifacts exist, this repository should not be treated as evidence of a completed BookMyShow implementation.
